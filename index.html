FRAMEPILOT 0.14.3

Replay. Inspect.
Try it your way.

Record and edit macros, inspect tight timings, and automatically capture replay videos.

  • Practice recording, tick stepping and reconstructed rewind
  • Input timeline, section loops and timing searches
  • MP4 recording with game audio, FPS and quality controls

Unresolved windows stay unmeasured. Pathfinder is a bounded replay search, not an unrestricted level solver.

♫F7

PETAL JUKEBOX 0.4.4

Your level.
Your soundtrack.

Find hosted NONG matches, import your own audio, and keep the version you chose ready for next time.

  • Hosted online song matches by song ID
  • Local audio imports and per-song offsets
  • Persistent selections without overwriting originals

Restart the song or level after switching. YouTube-only entries need a separate local audio import.

✦F8

PETAL CBF 0.1.0 beta

Between frames.
Inside your control.

A separate standalone component for GD 2.2091, with timestamped input substeps and no Geode requirement.

  • Optional installer checkbox; enable in its F8 menu
  • Native physics frequency stays unchanged
  • Suspends while FramePilot owns macro input

Development build. Use one CBF implementation at a time. Based on the MIT-licensed CBF algorithm by theyareonit/syzzi; in-game verification remains for the user.

✦Ctrl+F9

PETAL CLICKS 0.1.0 beta

Clicks for your showcase.

Includes Kenney’s CC0 mouse press and release sounds, ready to use.

  • Separate P1/P2 custom packs
  • Volume and pitch variation
  • Muted during FramePilot analysis

Click sounds use the game mixer, so FramePilot videos can capture them.

✦Ctrl+F10

PETAL RUN INFO 0.1.0 beta

Every run remembered.

See where your practice run began, and keep a saved history of attempts and completions.

  • Practice and StartPos labels
  • Saved runs and repeat completions
  • Themes, placement and font controls

FramePilot-controlled runs are excluded by default. Platformer uses elapsed level time.

✦Ctrl+F11

PETAL INPUT HUD 0.1.0 beta

Your inputs, on screen.

Show held jump, left and right inputs, press totals and one-second jump CPS.

  • Per-player input display
  • Corner and scale settings
  • Shared themes and fonts

The HUD observes gameplay input without adding clicks.

✦Ctrl+F12

DEATH REPLAY 0.1.0 beta

Keep the last attempt.

An optional rolling video buffer saves a short MP4 when you die.

  • 3–30 second buffer, 15–60 FPS
  • Optional game audio
  • Videos/PetalSuite/Death Replays

Enable the buffer in its menu. Capturing uses GPU/CPU resources; the available buffer length is shown.

Petal Utilities

Install the optional Utilities component and open it with Ctrl+F4. Petal noclip offers a customizable key (default F5), allowed-hit limit, collision tint and collision-free simulation-time accuracy. Tagged noclip runs stay out of regular completion totals. Use one noclip implementation at a time.

Death Replay supports Petal prevented deaths directly. Mega Hack compatibility uses an explicit noclip-session switch and depends on forwarded death callbacks; Save recent clip is available as a fallback. Gameplay compatibility still needs user testing.
